El proyecto consiste en un sistema de tienda, que tiene como objetivo llevar acabo guardado de transacciones, ventas, gastos, y consultar con las ganancias de manera diaria, mensual y anual.

El objetivo es ser escalable e implemente una interfaz grafica un GUI grafico y un sistema de base de datos MySQL.
Sin nada más que decir considero que este es un gran paso para desarrollar un proyecto real y bases fuertes realizando este proyecto.
